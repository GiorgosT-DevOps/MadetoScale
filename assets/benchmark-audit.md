## Recorded Feature Patterns

- Global header with logo, services dropdown, about-related dropdown, blog link, contact link, dark-mode toggle, mobile menu, and persistent start-project CTA.
- Mobile menu opens into a full navigation surface with the same primary conversion path.
- Repeated modal/video controls appear around showreel and testimonial media.
- Home page combines hero, featured work, service expertise, testimonial proof, long-form positioning, blog/insight cards, external AI prompt links, social links, and final CTA.
- Contact page includes hero, project planner CTA, email fallback, form fields, privacy acceptance, studio/trust details, FAQs, and final CTA.
- Project planner is a step-based enquiry flow starting with basic identity fields before collecting project detail.
- Work page has category filters, project cards, testimonial/CTA inserts, and a large archive model.
- Services page groups capabilities into Design, Develop, and Support, then supports the page with insight content and footer conversion.
- FAQ page groups questions into sections rather than one flat list.
- Process/support pages use trust-building narrative, review/testimonial sections, support-plan comparison, and repeated CTAs.
- Footer includes back-to-top utility, deep navigation columns, contact details, social links, and legal links.

## Made to Scale Changes Applied

- Added `project-planner.html` with a four-step guided enquiry flow.
- Added dedicated `faq.html`, `process.html`, `care-plans.html`, and `insights.html` pages.
- Updated navigation to include deeper studio pages, insights, a studio overview modal, and planner-led CTA.
- Added work filters for the current two case studies.
- Added homepage media strip, testimonial-style slider, AI prompt links, and richer repeated CTAs.
- Added care-plan comparison table and process detail page.
- Added back-to-top controls and a reusable studio overview modal.
- Preserved Made to Scale's own copy, imagery, palette, and founder-led positioning rather than copying MadeByShape assets or wording.
